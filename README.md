# Pensativity Solutions LLC

Professional innovation consulting and R&D commercialization website.

## Overview

This static website is built for Pensativity Solutions LLC and targets executives, founders, and investors looking to:
- commercialize an idea
- acquire or sell innovation opportunities
- build strategic R&D partnerships
- bring a concept to market

## Included pages
- `index.html` — homepage
- `contracts.html` — contracts and partnership models
- `styles.css` — styling and responsive layout
- `script.js` — contact form interaction

## Website deployment
This is a static site and is ready to deploy on GitHub Pages, Netlify, or Vercel.

For GitHub Pages:
1. Go to the repository settings
2. Open Pages
3. Set source to Deploy from a branch
4. Choose the `main` branch and save

The site will be available at:
https://TrebleWeight.github.io/innovation-business-website
